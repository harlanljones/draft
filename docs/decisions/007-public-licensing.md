# D-007: Public Licensing Boundary

Status: policy accepted; final licenses and counsel review remain open.

Treat code, source databases, normalized databases, outcome labels, trained models, reports, and
board artifacts as separate licensing objects. Withholding raw rows does not establish permission
to publish features, predictions, or aggregate comparisons.

Any Lahman use must pin a release and preserve CC BY-SA 3.0 attribution and obligations. Any
Chadwick use must pin a commit and preserve ODC-By 1.0 attribution. Counsel must determine how those
licenses apply to derived databases and public labels before publication. Restricted source terms
or permission letters override no project guardrail and never enter Git if confidential.

Until those reviews and a repository code license are selected, empirical outputs cannot be
published. Demo artifacts remain synthetic and retain `DEMO / NOT EMPIRICAL` labeling.
